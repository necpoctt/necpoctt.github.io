Angular 21 + Kendo UI 企業後台範例

作者：廖哲皓（Howard Liao）・Frontend Lead

GitHub 原始碼 線上展示

專案簡介

以 Angular 21 的 standalone 元件搭配 Kendo UI Grid 和 Charts，做出員工管理表格和數據儀表板，示範企業後台常見的分頁、排序、篩選。

實作重點

  • 路由用 loadComponent 延遲載入每個頁面，不需要 NgModule。
  • Kendo Grid 的分頁、排序、篩選都集中在一個 State 物件，透過 dataStateChange 事件統一處理。
  • Service 用 kendo-data-query 在前端模擬後端查詢，正式環境只要換成 HTTP 請求即可。
  • 用按鈕一鍵套用篩選條件，並自訂欄位顯示與中文介面文字。

使用技術

Angular 21 TypeScript Kendo UI for Angular RxJS Tailwind CSS Vitest

其他作品

  • 微前端示範：React 與 Vue 元件在同一頁共存
  • React + MUI 響應式網頁：桌機與手機分開元件
  • 可嵌入任何網站的聊天外掛（React + iframe）
