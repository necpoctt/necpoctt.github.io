React + MUI 響應式網頁：桌機與手機分開元件

作者：廖哲皓（Howard Liao）・Frontend Lead

GitHub 原始碼

專案簡介

用 React、Material UI 和 TypeScript 建立的 RWD 範例。依螢幕寬度在路由層切換桌機和手機兩套元件，並用 react-window 虛擬化處理大量資料。

實作重點

  • 用 MUI 的 useMediaQuery 在路由層決定載入桌機或手機版，並用 React.lazy 只下載需要的那一套。
  • 桌機版用 FixedSizeGrid 格狀排列，只渲染畫面上看得到的項目。
  • 手機版用 FixedSizeList 搭配 InfiniteLoader 做無限捲動，捲到底自動載入下一頁。
  • 共用元件（Button、TextField、Loading 等）都有 Testing Library 單元測試。

使用技術

React TypeScript Material UI React Router react-window Testing Library ESLint Prettier
