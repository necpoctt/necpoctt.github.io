微前端示範：React 與 Vue 元件在同一頁共存

作者：廖哲皓（Howard Liao）・Principal Engineer

GitHub 原始碼 線上展示 Medium 文章

專案簡介

在 Vue 3 主程式裡，透過 Web Components 同時載入 React 19 + ECharts 的圖表和 Vue 3 + Ant Design Vue 的表格，組成一個資源管理儀表板。

實作重點

  • 兩個元件庫各自用 Vite 的 library mode 打包成單一 JS 檔，主程式用 script 標籤載入即可使用。
  • Vue 元件用 defineCustomElement 轉成 Web Component；React 元件用自寫的轉換函式，在 Shadow DOM 裡用 createRoot 掛載。
  • 資料用 JSON 字串透過屬性傳入，事件用 CustomEvent 回傳給主程式。
  • Shadow DOM 隔離樣式，不同框架的元件互不干擾。

使用技術

Vue 3 React 19 TypeScript Vite library mode Web Components Shadow DOM ECharts Ant Design Vue
