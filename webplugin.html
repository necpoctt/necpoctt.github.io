可嵌入任何網站的聊天外掛（React + iframe）

作者：廖哲皓（Howard Liao）・Frontend Lead

GitHub 原始碼

專案簡介

以 React 和 Redux Toolkit 開發、透過 iframe 嵌入其他網站的聊天外掛。外掛和外層網站用 postMessage 溝通，樣式和程式完全隔離。

實作重點

  • 用 iframe 隔離樣式和 JavaScript，外掛不會影響對方網站，也不會被對方網站影響。
  • 啟動時透過 postMessage 向外層網站取得設定；展開或收合時通知外層網站調整大小。
  • 使用者登入後，前端向後端換取聊天服務的短期 token，第三方金鑰只放在後端。

使用技術

React TypeScript Redux Toolkit iframe postMessage Facebook Login
